# Hex Editor

**Version 1.0.0**

A hexadecimal editor using `UByteArrayOutputStream` from zoxweb-core as its data buffer.

## Features

- View and edit binary files
- Search and replace hex patterns
- Undo / Redo support
- Data type inspector
- Copy / Paste support

---

Built with Java Swing — package `io.xlogistx.gui.hexeditor`.
