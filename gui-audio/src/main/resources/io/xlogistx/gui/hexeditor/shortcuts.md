# Keyboard Shortcuts

## File Operations

| Shortcut | Action |
|---|---|
| `Ctrl+N` | New file |
| `Ctrl+O` | Open file |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save As |

## Navigation

| Shortcut | Action |
|---|---|
| Arrow Keys | Move cursor |
| `Page Up` / `Page Down` | Scroll page |
| `Home` / `End` | Start / end of line |
| `Ctrl+Home` / `Ctrl+End` | Start / end of file |
| `Ctrl+G` | Go to offset |
| `Tab` | Toggle hex/ASCII editing |

## Selection

| Shortcut | Action |
|---|---|
| `Shift`+Arrows | Extend selection |
| `Ctrl+A` | Select all |
| Double-click | Select byte |

## Editing

| Shortcut | Action |
|---|---|
| `0-9`, `A-F` | Edit hex nibble |
| `Delete` | Delete byte |
| `Backspace` | Delete previous byte |
| `Insert` | Insert zero byte |

## Clipboard

| Shortcut | Action |
|---|---|
| `Ctrl+C` | Copy (as hex) |
| `Ctrl+X` | Cut |
| `Ctrl+V` | Paste |

## Undo / Redo

| Shortcut | Action |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |

## Search

| Shortcut | Action |
|---|---|
| `Ctrl+F` | Find |
| `F3` | Find next |
| `Ctrl+H` | Replace |
